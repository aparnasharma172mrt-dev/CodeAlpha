# Student Grade Tracker – Task 1 (CodeAlpha Internship)

This is a **Student Grade Tracker** application created as part of **Task 1** of my **CodeAlpha Java Programming Internship**.

It is a Java-based console application that helps to store student details and calculate their grades, average score, highest score, and lowest score.

---

## 📌 Features

### **1. Student Details Management**

- Add multiple student records.
- Store:
  - Student name
  - Student grade

### **2. Grade Calculation**

- Calculates average score of all students.
- Finds highest score.
- Finds lowest score.
- Displays highest and lowest scoring students.

### **3. Student Report**

- Displays complete student grade report.
- Shows each student's name and grade.

### **4. ArrayList Implementation**

- Uses ArrayList to store and manage student data dynamically.

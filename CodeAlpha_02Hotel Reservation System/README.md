# Hotel Reservation System – Task 2 (CodeAlpha Internship)

This is a **Hotel Reservation System** application created as part of **Task 2** of my **CodeAlpha Java Programming Internship**.

It is a Java-based console application that allows users to view available rooms, make reservations, and manage hotel booking details.

---

## 📌 Features

### **1. Room Management**

- Display available rooms.
- View room details.
- Select rooms for booking.

### **2. Reservation System**

- Book a room by entering customer details.
- Store reservation information.
- Generate booking details.

### **3. Customer Details**

- Enter customer name.
- Store booking information.
- Manage reservation records.

### **4. Booking Management**

- Check room availability.
- Prevent booking of already reserved rooms.
- Display reservation details.
